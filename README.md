# Monte Carlo Common Source Amplifier

This project presents the complete design and verification of a BS170 common-source MOSFET amplifier developed in LTspice. The work includes DC bias analysis, transient response evaluation, small-signal amplification behavior, and a 100-run Monte Carlo simulation to quantify the effects of component tolerances on circuit performance. Results demonstrate amplifier robustness under realistic manufacturing variations and provide insight into analog circuit sensitivity and design margins.
